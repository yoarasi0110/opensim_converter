OpenSim 影片與 CSV 轉換工具（單人版）
==================================

一、如何開啟
1. 如果收到 ZIP 檔，先按右鍵「全部解壓縮」。
2. 開啟 OpenSimConverter 資料夾，雙擊 OpenSimConverter.exe。
3. 請保留 EXE 旁的 _internal 資料夾。搬到其他電腦時，複製整個
   OpenSimConverter 資料夾；只複製 EXE 會無法執行。
4. 本工具適用 Windows 64 位元，不需要另裝 Python、MediaPipe 或
   OpenSim Python 套件。要觀看模型與執行 IK，仍需使用 OpenSim 軟體。

二、影片轉成 CSV 與 TRC
1. 選「選影片（只偵測一人）」。
2. 在「影片 / CSV」按「瀏覽」，選擇 MP4 影片。
3. 在「OpenSim 模型」按「瀏覽」，選擇 .osim 模型。
   模型必須含 MarkerSet，且具備程式可對應的全身關節 markers。
   目前已驗證的是原先使用的 FullBodyModel（83 個 markers）。
4. 在「輸出資料夾」按「瀏覽」，選擇存放結果的位置。
5. 請使用單人、全身入鏡的影片。程式只偵測一人，不依衣服顏色篩選。
6. 按「開始轉換」。紀錄區會顯示影片分析進度。
   分析時間會依影片長度與電腦速度而不同。
7. 顯示完成後，按「開啟輸出資料夾」。

這個模式會一次完成：影片偵測 → raw CSV → clean CSV → 模型 marker
擴增與貼合 → marker CSV → TRC，不必手動再執行第二個程式。

每次轉換都會建立「影片名稱_日期時間」子資料夾，避免蓋掉先前結果。
主要輸出：
- person01_raw.csv：MediaPipe 原始全身 33 個 landmarks。
- person01_clean.csv：清理與平滑後的 33 個 landmarks。
- person01_markers.csv：貼合所選模型、擴增後的 marker 座標，單位 m。
- person01.trc：供 OpenSim 匯入與執行 IK 的 marker 軌跡。
- manifest.json：來源影片、FPS、模型 markers 與輸出檔資訊。
- settings.json：這次轉換所選的檔案與設定。
- conversion.log：進度及錯誤紀錄。

三、已有 CSV，轉成 TRC
1. 選「選已有的 CSV」。
2. 選擇本工具產生的 clean.csv、raw.csv 或 markers.csv。
   建議優先選 clean.csv；外部 CSV 必須符合相同的欄位與座標格式。
3. 選擇 .osim 模型和輸出資料夾。
4. 程式自動讀取 CSV 的人物編號，並依 frame/time 推算取樣率。
   CSV 必須只含一個人物；本工具的單人輸出符合此條件。
5. 按「開始轉換」，完成後開啟輸出資料夾。

全身 raw/clean CSV 會重新貼合模型並擴增 markers。
markers.csv 已含貼合後座標，程式會檢查 marker 名稱是否屬於模型，
直接輸出 TRC，避免重複貼合。請選擇產生該 markers.csv 時使用的模型。

輸出包含「CSV 名稱.trc」及「CSV 名稱_model_markers.csv」。
手部 landmarks CSV 由原 CSVToTRC 轉換器處理，需選相容的手部模型。

四、在 OpenSim 使用 TRC
1. 在 OpenSim 開啟與轉換時相同的 .osim 模型。
2. 開啟 Inverse Kinematics 工具，選擇輸出的 .trc 作為 Marker data。
3. 檢查模型 marker 名稱與 TRC 欄位名稱是否相同，設定正確時間範圍，
   再執行 IK。
4. 本工具輸出 TRC，沒有自動執行 IK 或肌肉分析。
5. 單一攝影機估計的 3D 座標與擴增 markers 仍可能有深度、遮擋、
   比例或姿態誤差，請以原影片比對動作，確認後再進行分析。

五、遇到問題
- 找不到影片：請使用可正常播放的 MP4，並確認檔案存在。
- 模型 marker 不相容：請使用含 MarkerSet 且與全身關節對應相容的模型。
  換模型不保證每個 marker 都可擴增；未支援的名稱會顯示在紀錄。
- CSV 缺少 landmarks：使用本工具產生的 clean.csv，並確認 CSV 只含一人。
  若影片完全沒有偵測到某個 landmark，請改用較清晰、全身入鏡的影片。
- 輸出失敗：選可寫入的資料夾，例如桌面、文件或隨身碟內資料夾。
- 中途按「停止」：結果可能不完整，請重新轉換並使用新資料夾的結果。
- 啟動失敗：確認 ZIP 已完整解壓縮，EXE 與 _internal 放在一起。
- 需要排查：提供輸出資料夾中的 conversion.log 和 settings.json。

六、程式檔名稱（給需要維護原始碼的人）
- VideoToCSV.py：原 dance_video_to_opensim.py，預設改為偵測一人。
  此程式實際包含影片 → CSV → marker 擴增 → TRC 的完整流程。
- CSVToTRC.py：原 csv_to_trc_auto_fit.py，CSV 自動貼合模型與 TRC 輸出。
- OpenSimConverter.py：圖形介面、選檔、單人轉換與 CSV 擴增整合。

一般使用者只需開啟 OpenSimConverter.exe，不需要操作 Python 原始碼。
